# Glacitek – 電腦周邊配件網站

一個純前端開發的電商模擬平台，由 HTML / CSS / JavaScript（無框架）實作<br>目的在呈現 RWD 響應式設計、產品輪播、購物車操作、搜尋功能與頁面跳轉流程。

## 功能展示

- **產品專區展示**  
  提供鍵盤、滑鼠、耳機等多種配件，搭配各自的介紹與視覺效果。

- **最新資訊公告**  
  顯示促銷公告、系統維運與新品預告，模擬電商更新流程。

- **使用者心得分享區塊**  
  顯示多則仿真使用者回饋，增加真實感與互動性。

- **RWD 響應式設計**  
  使用 CSS Flexbox / Grid 與 Media Query 搭配，兼顧桌機與手機瀏覽體驗。

- **無框架 SPA 模擬**  
  自製路由與頁面跳轉，模擬單頁應用流程。

- **互動效果**  
  利用 CSS 控制條款、滑動特效與 DOM 操控營造互動感。

---

## 技術部分

- **前端技術**：HTML5、CSS3、原生 JavaScript (ES6+)、Flexbox、Grid
- **資料操作**：DOM 操控、sessionStorage 持久化資料、事件委派管理
- **設計風格**：響應式設計 (RWD)、動態資料渲染
- **瀏覽器操作**：模擬 URL 搜尋參數跳轉、資料狀態保存與還原
